Turn on automatic wallet backup

This opens as its own tab on purpose — the browser's file picker only works from a real top-level page, not from a panel embedded inside another site.

Clicking "Choose backup file location" below will open your browser's own, ordinary file save dialog. Pick (or create) a file there once, and from then on this extension will silently keep that file up to date every time something meaningful changes in your wallet — no further prompts, no repeated downloads.

If you skip this: uninstalling the extension, clearing your browser data, or losing this device will lose your identity and everything it holds, for good, unless you've separately made a manual export (Settings → Full backup) or have another recovery method set up.

One more thing this needs, for a technical reason: the actual silent writes can only happen from this window itself, not from the wallet panel you opened this from. So this window needs to stay open after setup — minimized is completely fine — for automatic backup to keep working. Closing it pauses backups until you reopen it from Settings; nothing is lost by that, it just stops updating until you do.

Tip: if you'd like this backup to also survive losing this device entirely, choose a location inside a folder your cloud storage app already keeps in sync — OneDrive, Google Drive, iCloud Drive, Dropbox, or similar. That sync app will then carry a copy off this device automatically, with nothing extra to set up here.

Unlock your wallet first

Automatic backup can only be set up for an already-unlocked local password identity. Go back to the wallet panel, unlock it, then reopen this from Settings.
