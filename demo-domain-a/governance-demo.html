An open assembly, a vote nobody can cast twice, and a deadline nobody has to enforce by hand

Not a fixed committee of named officers — anyone can join, anyone who's joined can propose, everyone gets exactly one vote, the tally is visible the whole time, and the vote closes itself the instant the clock says so.

The treasury-approval demo proves K-of-N signing among a small, fixed, named roster — the right shape for a committee. This page proves a genuinely different consensus shape: open enrollment (anyone can become a member, any member can propose), one-member-one-vote with a transparent running tally (visible the moment each vote lands, not hidden until some threshold crosses), and a deadline-based close (nobody decides when voting ends — SPEC.md §5.10's same "the clock already decided" reasoning credential expiry uses, applied to a vote instead). Every step below is a genuine, live call to this domain's own server.

One honest limitation, stated plainly: membership is free to mint, on purpose — this proves the MECHANISM (one credential, one vote, a real transparent tally, a real self-closing deadline), not a Sybil-resistant one-person-one-vote system. A real deployment would gate membership behind something costlier than a click — an invitation, a KYC check, a staked deposit — the same way a real election gates who gets a ballot.

Act 1 — the assembly is open to anyone

Three visitors join by minting an ordinary membership credential (atlas.demo.governance.membership) — the same one-click, no-approval-needed shape every other membership on this site already uses. No invitation, no vetting: that's the point being disclosed above.

Act 2 — any member can put something to a vote

Alice proposes it. The deadline is a plain future timestamp — voting closes the instant the clock passes it, not when anyone decides to close it.

Act 3 — one member, one vote, tallied live

Every vote below lands immediately and is visible to anyone — no waiting for all votes to arrive, no threshold to cross first.

Act 4 — try to break it

One-member-one-vote and membership-gated voting are both real constraints, not just UI — the two buttons below try to violate each one directly.

Act 5 — the deadline passes, and anyone can get a signed decision

Once voting closes, requesting this asks the domain to sign its own factual record of the outcome — a small, independently-verifiable credential in its own right, callable by anyone, any number of times, always producing the same result.

Verify any decision from this page, independently

Paste a decision's raw JSON below — copy one from the "View raw decision" details box above. This runs entirely in your own browser: it fetches this domain's public key directly, then checks the signature itself.

Alice, Bob, Charlie, and Dana are ordinary ECDSA keypairs generated fresh in your own browser tab, exactly like every other demo on this site — no accounts, nothing stored server-side beyond the credentials and votes themselves. Back to the plaza.
