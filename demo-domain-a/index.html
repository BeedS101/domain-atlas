Domain Atlas Alpha Node

An ordinary web page — nothing about it looks different.

This domain publishes a spatial manifest at /.well-known/spatial.json declaring five worlds — Plaza, Museum, Arena, Market, and Lobby — under one identity, plus a portal out to a second, independent domain. A Domain Atlas-aware client can detect all of that and offer to render it.

Walking into these spaces needs the wallet extension

This page looks like nothing on its own — a Domain Atlas-aware browser extension is what actually detects the manifest above and offers to open a world, with a wallet identity to hold whatever you pick up along the way.

  1. Get the extension from the GitHub repo (the extension/ folder)
  2. In Chrome, open chrome://extensions, turn on Developer mode, then Load unpacked and select that folder
  3. Reload this page — it'll offer to enter the space, and walk you through setting up a wallet identity the first time

...and a transfer can require more than one signature

A treasury transfer that only executes once enough of a named group of officers sign off, never on any single signature alone — each one fetching the exact thing being approved straight from this server before ever signing it, not trusting whatever anyone else's page claims it says. ...and a second, independent key can vouch for something it didn't issue

A key that never issued something — standing in for an auditor, a regulator, a certifying body — signs its own opinion about it, checkable by anyone. No custody, no shared infrastructure, and no cooperation needed from whoever issued the thing being reviewed. The same protocol works identically across two genuinely separate domains; this demo keeps both identities on one server so it runs standalone. Try the attestation demo →

...and a suspicious transfer can be frozen, then decided later

A stolen credential moves through a real theft and an optional laundering hop, gets suspended on report, and then either gets released once it's a false alarm or clawed back straight into its rightful owner's wallet, wherever it's since moved to. Try the suspend & clawback demo →
