SPEC.md §13 — a credential handed to someone with nothing but an inbox.

Every other demo on this site hands a credential to a wallet — a public key generated right here in the browser. This one doesn't: the idea is a credential that reaches someone with nothing but an inbox, no install, no wallet, no app on the receiving end at all. Step 1 below issues a real, signed voucher. Step 2 is a mockup of what sending it looks like — this page doesn't dispatch a real email itself.

What this looks like for a real business

An event ticket bought by a stranger who'll never install anything, a gift voucher a customer should be able to forward to a friend with no app involved at all. The issuer's signing key is all that's required — no derived keys, no custodial account, no per-address identity to manage. Whoever currently holds the one valid copy may act on it, the same bearer rule this site's own self-serve routes already run on, just carried over email instead of a signed HTTP call.

What a live deployment does, entirely through email

None of this runs in the mockup above — it's what this domain's real /atlas/asset/transfer-to-email endpoint (SPEC.md §13.1) does once an operator turns on outbound mail for this mailbox. The voucher is revoked and a fresh one minted and emailed, only once the mail server actually accepts delivery. Whoever receives it can forward that exact message on again — CC the next recipient, done — and this domain's own mailbox notices on its next check and moves the ticket again, the same way. A typo'd or dead address is caught before anything is finalized against it; an address that bounces after delivery was already accepted is caught too — correlated back to the exact send that produced it, and returned to whoever sent it with a plain explanation, never naming where it actually went. Forwarding to more than one address at once is refused outright rather than guessed at.

Nothing on this page is stored in a database anywhere. The voucher is a signature from this domain over a set of facts — verifying it means checking that signature, not looking anything up. Back to Neighbor Workshop.
