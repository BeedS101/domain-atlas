Neighbor Workshop

A second, independent domain on port 8002 — a single-world manifest (a worlds array of length one) that portals back to Example Plaza's plaza world on port 8001, proving cross-domain traversal works alongside the same-origin world-to-world portals over there.

Walking into these spaces needs the wallet extension

This page looks like nothing on its own — a Domain Atlas-aware browser extension is what actually detects the manifest above and offers to open a world, with a wallet identity to hold whatever you pick up along the way.

  1. Get the extension from the GitHub repo (the extension/ folder)
  2. In Chrome, open chrome://extensions, turn on Developer mode, then Load unpacked and select that folder
  3. Reload this page — it'll offer to enter the space, and walk you through setting up a wallet identity the first time

...and this page can talk to that wallet directly, without you ever entering a world

Same wallet extension as above — but this domain also declares a policy.walletBridge, which lets an ordinary page script ask the wallet a question, request a signature, or hand it an asset to consider keeping, each gated by this domain's own manifest and your own explicit approval on a prompt the page itself can't draw over or fake.
