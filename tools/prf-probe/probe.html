WebAuthn PRF probe

This page checks whether this browser and authenticator can derive a secret from a passkey (the WebAuthn PRF extension). It creates a few disposable passkeys named "Domain Atlas PRF probe" and, where PRF works, asks them for a few values. The full diagnostic first tries an ordinary passkey with no PRF, then PRF, so a failure can be told apart from missing PRF support. It stores nothing, reads no wallet and contacts no site. Each step may show a Windows Hello or security key prompt. Delete the passkey afterwards in Windows Settings > Accounts > Passkeys if you wish.
