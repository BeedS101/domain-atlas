WebAuthn PRF probe

This page checks whether this browser and authenticator can derive a secret from a passkey (the WebAuthn PRF extension). It creates one disposable passkey named "Domain Atlas PRF probe" and asks it for a few values. It stores nothing, reads no wallet and contacts no site. Each step may show a Windows Hello or security key prompt. Delete the passkey afterwards in Windows Settings > Accounts > Passkeys if you wish.
