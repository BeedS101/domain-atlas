Operator key

Actions that change something are signed in this page by an administrator key you choose from a file on this computer. The file is read by your browser only: the private key is not uploaded, not stored and not sent, and the page keeps only a signing handle that cannot be exported, and only until the action is done (or, if you choose to, for five minutes of inactivity at most). A handle that cannot be exported can still sign while it is loaded, so page code that has been tampered with could use it for anything that key may do. Use a key limited to the Studio actions. Recovery, rollback and activation are signed with the command line tool, not here (tools/chainlabs-operator.js).

      Open a coin on the ledger

      A registered coin is only a record. Opening it creates its ledger on this domain through spend34.php: entry 0 credits the treasury. A coin that is already open is refused, so nothing is opened twice. A multi authority coin opens only when every partner domain has signed its genesis, and a partner signs only after its own operator has accepted the proposal on that domain. The first press sends the proposal; when the partner operators have accepted, press the button again, which is a new signed request. If one does not answer, press it again later and only the missing ones are asked. After that the coin is in the scanner, and a wallet that adds this domain sees what it holds.

      Coins proposed to this domain

      When another domain's authority proposes a coin of several domains that names this domain, this domain signs its genesis only after you accept it here. Read every term below and compare the genesis digest with the one the authority shows, by another route than this page. Accepting names that coin and that digest, is signed with your operator key, and does not open the coin: the authority opens it with a new request of its own. Once this domain has signed, the coin can no longer be declined here. Listing and deciding are signed requests, so choose your key file for each (or keep the key loaded for a few minutes); the old operator token is not accepted for them.
