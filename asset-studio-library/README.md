# Asset Studio reusable library

This directory contains **version-controlled, trusted starter templates** only. It is not user upload storage and is not the issuer's authoritative holdings, issuance, or revocation store.

- `templates/`: reviewable descriptions and metadata for starter templates.
- `models/`: optional curated GLB source assets.
- `textures/`: curated media.
- `manifests/`: approved example placement/rendering manifests.

Do **not** commit user uploads, private drafts, private keys, live credentials or issuance journals here. User-created files belong in a separate writable directory outside the web document root (see `docs/asset-studio-storage.md`).

The Studio is still a preview. No minting or upload path is enabled.
